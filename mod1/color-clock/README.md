# Color / Time

A live color clock that translates local time into a hexadecimal color. The hours, minutes, and seconds form the RGB channels, so the background shifts every second. Copy the current hex value with the button below the clock.

## Run locally

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build in `dist/`.
- `npm run preview` serves the production build locally.
- `npm run lint` checks the project with ESLint.

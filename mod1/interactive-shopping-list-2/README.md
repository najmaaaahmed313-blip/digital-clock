# Interactive Shopping List

A simple shopping list app built with HTML, CSS, and JavaScript.

## Features
- Add items with a name and price
- Mark items as purchased
- Edit item name and price inline
- Delete items from the list
- View the total cost of all items
- Clear the full list
- Automatically save the list in browser localStorage

## How to run
1. Open the project folder in a browser.
2. Open `index.html` directly in the browser, or serve the folder with a local static server.

## Project files
- `index.html` – page structure
- `styles.css` – styling
- `main.js` – shopping list logic and localStorage persistence

## Notes
The list is saved in the browser using `localStorage`, so it stays available after a refresh.
